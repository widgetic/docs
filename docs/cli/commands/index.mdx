The `widgetic` command line has one binary and two namespaces. Every command is generated from the contracts the gateway publishes, so this reference lists exactly what the CLI can do.

- `widgetic api <group> <command>`: 159 operations of the public REST API, in 14 groups.
- `widgetic mcp <command>`: 34 tools of the MCP server (tool contract 1.14.0), the AI build tools.
- `widgetic auth`, `widgetic doctor`, `widgetic update`, `widgetic schema`, `widgetic completion`: log in, check the install and the servers, look for a newer version of the CLI and install it, print the schema of one command, and complete commands with the Tab key.
- `widgetic api call <operationId>` and `widgetic mcp call <tool>` run a command by the name the contract gives it.

## Every command takes

| Flag | What it does |
| --- | --- |
| `--json` | Print the result as one line of JSON. An error is `{"error":{"code","message","status","requestId"}}` on standard error. Nothing is ever asked. |
| `--dry-run` | Print what would be sent (the API key is left out) and send nothing. |
| `--yes` | Go ahead without asking, for a command that deletes or changes something. Needed where there is no terminal. |
| `--profile <name>` | The saved API key to use (default: `WIDGETIC_PROFILE`, else `default`). |
| `--timeout <seconds>` | Give up on a call after this many seconds (default: 60). |

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | It worked. |
| 1 | Anything else: a bug, or a server error that was not expected. |
| 2 | The command line or a JSON document is wrong. Nothing was sent. |
| 3 | Authentication or plan: no key, or a 401, 402 or 403. |
| 4 | Not found (404 or 410). |
| 5 | The server refused the request (400, 409, 422, another 4xx, or a tool that answered with an error). |
| 6 | Rate limited or unavailable (429, 502, 503, 504), a timeout, or no network. A `Retry-After` is honoured. |
| 7 | This CLI is too old (426): `widgetic update`, or `npm install -g @widgetic/cli@latest`. |
