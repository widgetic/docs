## `widgetic api uploads uploads-get`

List the account's uploads

- Request: `GET /uploads`
- Operation: `uploadsGet` (`widgetic api call uploadsGet` runs it by that name)
- Also written: `widgetic api uploads list`
- Works with any API key.

| Flag | Takes | Required | What it does |
| --- | --- | --- | --- |
| `--limit <int>` | integer |  | Maximum number of files to return (default: 50) |
| `--managed-user-id <uuid>` | uuid |  | List only the files uploaded for this managed user (Widgetic's id for the user). Send this or `managedUserExternalId`, not both. |
| `--managed-user-external-id <text>` | text |  | List only the files uploaded for the managed user you registered with this `externalId` (your own identifier for the user). Send this or `managedUserId`, not both. |

## `widgetic api uploads uploads-post`

Upload a file

- Request: `POST /uploads`
- Operation: `uploadsPost` (`widgetic api call uploadsPost` runs it by that name)
- Also written: `widgetic api uploads create`
- Works with any API key.

| Flag | Takes | Required | What it does |
| --- | --- | --- | --- |
| `--file <path>` | path of a file | yes | The file to store |
| `--context-type <text>` | one of `widget-codegen`, `browser-ic`, `content-property` |  | What the file is for. Send `content-property` for media that becomes widget content (images, video and PDF); the other values are used by Widgetic's own editor. (default: content-property) |
| `--source <text>` | one of `chat-upload`, `chat-screenshot`, `browser-ic-screenshot`, `preview-screenshot`, `file-browser-upload` |  | Which part of the product, or which client, the file comes from (default: file-browser-upload) |
| `--managed-user-id <uuid>` | uuid |  | Upload the file for one of your managed users, by Widgetic's id for the user. Send this or `managedUserExternalId`, not both. |
| `--managed-user-external-id <text>` | text |  | The same, by your own identifier for the user, the `externalId` you gave when you created the managed user. Send this or `managedUserId`, not both. |
| `--purpose <text>` | one of `canvas`, `chat`, `field` |  | Where in your product you use the file. It is kept with the file, so that a customer's storage can be counted by purpose (`getManagedUserStorageUsage`). |
