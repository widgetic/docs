The Widgetic canvas is planned to give you a full widget creation and editing experience that you can embed directly in your platform.

<Warning>
  **Planned. Not available yet.** A Widgetic editor that you can mount in your own page does not exist today. The editor runs on [widgetic.com](https://widgetic.com) for a signed-in account only. The UI SDK (`@widgetic/ui-sdk`) is not published, and the `/ui/components` calls only keep a record of a mount: they show nothing in your page. This page describes the design we plan to ship, and it can change, so do not build on it yet.

  To let your customers make and show widgets today, use the API with your own screens (see [Widgets](/docs/api/widgets) and [Compositions](/docs/api/compositions)) and show the result with the embed code.
</Warning>

## Overview

The canvas embedding system is planned to consist of:

1. **UI SDK**: A JavaScript library for mounting UI components
2. **Widget Creator**: The main widget creation experience
3. **Composition Editor**: For editing widget layouts
4. **Embed Editor**: For configuring embed settings

## Installation

The UI SDK is not on npm yet, so `npm install @widgetic/ui-sdk` finds nothing today. Only the API SDK, `@widgetic/api-sdk`, is published.

## Basic Usage

The calls below exist in the API today. They are shown here to explain the planned design: `mountComponent` only records that a component was mounted, and nothing appears in your page.

### 1. List Available Components

First, retrieve the list of available UI components:

```typescript
import { UIComponentsApi } from '@widgetic/api-sdk';

const ui = new UIComponentsApi('wgt_prt_your_partner_key');
const { components } = await ui.listComponents();

// Returns: [
//   { id: 'widget-creator', name: 'Widget Creator', ... },
//   { id: 'composition-editor', name: 'Composition Editor', ... },
//   { id: 'embed-editor', name: 'Embed Editor', ... }
// ]
```

### 2. Get Component Manifest

Retrieve the component manifest for assets and configuration:

```typescript
const manifest = await ui.getComponentManifest({ componentId: 'widget-creator' });

// manifest.assets.js - JavaScript files to load
// manifest.assets.css - CSS files to load
// manifest.config - Component configuration options
```

### 3. Mount the Component

Mount the component in your DOM:

```typescript
const { instanceId, mountStatus } = await ui.mountComponent({
  componentId: 'widget-creator',
  mountRequest: {
    container: 'widgetic-canvas-container',
    theme: {
      mode: 'dark',
      colors: {
        primary: '#6366F1',
        background: '#1F2937'
      }
    }
  }
});

if (mountStatus === 'success') {
  console.log('Canvas mounted:', instanceId);
}
```

### 4. Unmount When Done

Clean up when the component is no longer needed:

```typescript
await ui.unmountComponent({
  componentId: 'widget-creator',
  instanceId: instanceId
});
```

## Theming

Customize the canvas appearance to match your brand:

```typescript
const theme = {
  mode: 'light', // or 'dark'
  colors: {
    primary: '#6366F1',    // Primary accent color
    secondary: '#8B5CF6',  // Secondary color
    background: '#FFFFFF', // Background color
    text: '#1F2937'        // Text color
  },
  typography: {
    fontFamily: 'Inter, sans-serif',
    fontSize: '14px'
  }
};
```

## Event Handling

Listen for events from the embedded canvas:

```typescript
// In your mount configuration
const { instanceId } = await ui.mountComponent({
  componentId: 'widget-creator',
  mountRequest: {
    container: 'widgetic-canvas-container',
    callbacks: {
      onWidgetCreated: (widget) => {
        console.log('New widget created:', widget.id);
      },
      onWidgetSaved: (widget) => {
        console.log('Widget saved:', widget.id);
      },
      onError: (error) => {
        console.error('Canvas error:', error);
      }
    }
  }
});
```

## Complete Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>Widget Creator</title>
  <style>
    #widgetic-canvas-container {
      width: 100%;
      height: 100vh;
    }
  </style>
</head>
<body>
  <div id="widgetic-canvas-container"></div>
  
  <script type="module">
    import { UIComponentsApi } from '@widgetic/api-sdk';

    // The short-lived token comes from your own server (see Security Considerations).
    // The partner key never goes in the page.
    const { token } = await (await fetch('/your-server/widgetic-token')).json();
    const ui = new UIComponentsApi(token);
    
    async function initCanvas() {
      try {
        const { instanceId, mountStatus } = await ui.mountComponent({
          componentId: 'widget-creator',
          mountRequest: {
            container: 'widgetic-canvas-container',
            theme: {
              mode: 'dark',
              colors: {
                primary: '#6366F1'
              }
            }
          }
        });
        
        if (mountStatus !== 'success') {
          throw new Error('Failed to mount canvas');
        }
        
        console.log('Canvas ready:', instanceId);
      } catch (error) {
        console.error('Failed to initialize canvas:', error);
      }
    }
    
    initCanvas();
  </script>
</body>
</html>
```

## Security Considerations

<Warning>
  Never expose your partner API key in client-side code. Use the token exchange flow to obtain short-lived tokens for browser usage.
</Warning>

```typescript
import { TokensApi } from '@widgetic/api-sdk';

// Server-side: exchange the partner key for a short-lived token
const tokens = new TokensApi(process.env.WIDGETIC_PARTNER_KEY!);
const { token } = await tokens.exchangeToken({
  exchangeTokenRequest: {
    scopes: ['compositions:read', 'widgets:read'],
    expiresIn: 1800 // seconds, 60 to 3600
  }
});

// Send the token to the client, and use it there
const ui = new UIComponentsApi(token);
```

The token records the scopes you ask for, but the API does not check them on each call yet, so treat the token as having the access of the key that made it until it expires. Keep the lifetime short, and never send the key itself to a browser. See [Authentication](/docs/authentication) for the scopes you can ask for.
