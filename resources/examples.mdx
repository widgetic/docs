This page provides practical code examples for common integration scenarios. Run them on your server: a key in a browser page can be read by every visitor.

## Quick Start

### Initialize the SDK

```typescript
import { 
  WidgetsApi, 
  CompositionsApi, 
  CanvasesApi 
} from '@widgetic/api-sdk';

// Initialize with API key
const widgets = new WidgetsApi(process.env.WIDGETIC_API_KEY);
const compositions = new CompositionsApi(process.env.WIDGETIC_API_KEY);
const canvases = new CanvasesApi(process.env.WIDGETIC_API_KEY);
```

### Using Async Token Provider

For short-lived tokens that rotate (see [Authentication](/docs/authentication) for token exchange):

```typescript
import { WidgetsApi } from '@widgetic/api-sdk';

const widgets = new WidgetsApi({
  accessToken: async () => {
    // Fetch a fresh short-lived token from your backend, which makes it with token exchange
    const response = await fetch('/api/widgetic-token');
    const { token } = await response.json();
    return token;
  }
});
```

## Fetching Data

### List Every Widget with Pagination

`GET /widgets` takes `page` and `size`, and is always newest first. `meta.hasNextPage` says whether to ask for another page:

```typescript
async function listEveryWidget() {
  const allWidgets = [];
  let page = 1;
  let hasMore = true;

  while (hasMore) {
    const { data, meta } = await widgets.getWidgets({ page, size: 100 });

    allWidgets.push(...(data ?? []));
    hasMore = (meta as { hasNextPage?: boolean } | null)?.hasNextPage ?? false;
    page++;
  }

  return allWidgets;
}
```

### Batch Fetch Multiple Widgets

```typescript
const widgetIds = [
  '123e4567-e89b-12d3-a456-426614174000',
  '223e4567-e89b-12d3-a456-426614174001',
  '323e4567-e89b-12d3-a456-426614174002'
];

// A widget that cannot be returned comes back in `errors`, with the reason
const { widgets: batchedWidgets, errors } = await widgets.getWidgetsBatch({
  getWidgetsBatchRequest: { widgetIds }
});
```

## Managing Canvases

### Create and Update a Canvas

```typescript
// Create a new canvas
const canvas = await canvases.createCanvas({
  createCanvasRequest: {
    persistenceKey: `project_${projectId}_canvas_${Date.now()}`,
    canvasContent: {
      version: 1,
      elements: [],
      settings: {
        background: '#ffffff',
        gridSize: 10
      }
    }
  }
});

console.log('Created canvas:', canvas.id);

// Update the canvas
const updated = await canvases.updateCanvas({
  id: canvas.id,
  updateCanvasRequest: {
    canvasContent: {
      version: 2,
      elements: [
        {
          id: 'text-1',
          type: 'text',
          content: 'Hello World',
          position: { x: 100, y: 100 }
        }
      ],
      settings: {
        background: '#f5f5f5',
        gridSize: 10
      }
    }
  }
});
```

## Partner Integration

### Create Managed Users

A managed user is a record of one of your customers. It is not a login, and it does not own anything. See [Managed Users](/docs/partners/managed-users).

```typescript
import { randomUUID } from 'node:crypto';
import { ManagedUsersApi } from '@widgetic/api-sdk';

const managedUsers = new ManagedUsersApi(process.env.WIDGETIC_PARTNER_KEY);

// Create a managed user for your customer. Leave manager_id out: it defaults to you.
// The API needs an Idempotency-Key header, and the SDK does not add one, so pass it in the second argument.
const user = await managedUsers.createManagedUser(
  {
    newManagedUser: {
      external_id: `myapp_user_${customerId}`,
      metadata: {
        firstName: customer.firstName,
        lastName: customer.lastName,
        email: customer.email,
        plan: customer.subscriptionPlan
      }
    }
  },
  async ({ init }) => ({ headers: { ...init.headers, 'Idempotency-Key': randomUUID() } })
);

// Store the mapping
await db.widgeticUsers.create({
  customerId,
  widgeticUserId: user.id
});
```

## Error Handling

### Robust API Client

The SDK throws a `ResponseError`. The HTTP status is `error.response.status`, and `error.code` holds the machine-readable code from the API's answer:

```typescript
import { CompositionsApi, ResponseError } from '@widgetic/api-sdk';

class WidgeticClient {
  private compositions: CompositionsApi;
  
  constructor(apiKey: string) {
    this.compositions = new CompositionsApi(apiKey);
  }

  async getComposition(id: string, attempt = 1) {
    try {
      const { data } = await this.compositions.getCompositionById({ id });
      return data;
    } catch (error) {
      if (!(error instanceof ResponseError)) {
        throw error;
      }
      const status = error.response.status;
      if (status === 404) {
        return null; // Composition not found
      }
      if (status === 401) {
        throw new Error('Invalid API key');
      }
      if (status === 429 && attempt < 4) {
        // Wait for as long as the API asks, then try again
        const retryAfterSeconds = Number(error.response.headers.get('retry-after')) || 5 * attempt;
        await this.sleep(retryAfterSeconds * 1000);
        return this.getComposition(id, attempt + 1);
      }
      throw error;
    }
  }

  private sleep(ms: number) {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}
```

## Embedding Widgets

A widget is shown on a page through a composition, and the page needs only the composition id. There is no key in the page.

### Basic Embed

```html
<!DOCTYPE html>
<html>
<head>
  <title>Widget Demo</title>
</head>
<body>
  <script src="https://cdn.widgetic.com/sdks/browser/embed-sdk.js?v=6"></script>
  <widgetic composition-id="YOUR_COMPOSITION_ID" resize="fill-width" width="800" height="450" autoscale="on" adaptive="480" embed-target="site"></widgetic>
</body>
</html>
```

### Embed as a Pop-up

`embed-target` decides where the widget appears: `site` inside the page, `overlay` as a pop-up, and `mixed` both. The overlay is the default. These attributes come from the composition's `embedSettings`, so build them from the saved settings (see [Compositions](/docs/api/compositions#embedding-compositions)):

```html
<script src="https://cdn.widgetic.com/sdks/browser/embed-sdk.js?v=6"></script>
<widgetic composition-id="YOUR_COMPOSITION_ID" resize="fill-width" width="800" height="450" autoscale="on" adaptive="480" embed-target="overlay" overlay="enabled" overlay-position="center-center" event-trigger="exit-intent" overlay-backdrop="false"></widgetic>
```
