Widgetic can be integrated with various platforms and services to enhance your workflow. A widget is shown on a page through a composition, and the page needs only the composition id: there is no key in the page.

## Embed Code

This is the code that every example below uses. Put your own composition id in it:

```html
<script src="https://cdn.widgetic.com/sdks/browser/embed-sdk.js?v=6"></script>
<widgetic composition-id="YOUR_COMPOSITION_ID" resize="fill-width" width="800" height="450" autoscale="on" adaptive="480" embed-target="site"></widgetic>
```

The Embed tab writes the same code from the composition's saved settings. See [Embed Script](/resources/sdks#embed-script) for what each attribute does.

<Note>
  If you limit the websites that may show your widgets, add every address that will show one, including preview and staging addresses. A page on an address that is not on the list shows nothing. See [Security](/resources/security).
</Note>

## CMS Integrations

Paste the embed code wherever the platform lets you add custom HTML.

### WordPress

1. Add a "Custom HTML" block
2. Paste the embed code
3. Update the page

### Webflow

1. Add an Embed element
2. Paste the embed code
3. Publish your site

### Shopify

1. Open the theme editor and add a "Custom Liquid" section where the widget should go
2. Paste the embed code
3. Save the theme

## E-commerce

### Product Configurators

Use widgets as interactive product configurators. The embed shows what its composition holds, so keep the widget up to date by saving your product data to the composition from your server whenever your catalogue changes. See [Compositions](/docs/api/compositions) for how to save a composition.

### Pricing Calculators

The same applies to pricing calculators: save your plans and prices to the composition, and every page that embeds it shows them.

<Note>
  This page does not document a way for the `<widgetic>` tag to hand a visitor's choice back to your page, for example to add a configured product to a cart. Build that step on your own page, around the embed.
</Note>

## Marketing Tools

### Email Marketing

Email programs do not run scripts or embedded frames, so a widget cannot run inside an email. Send a static image of your own (a screenshot of the widget) that links to a page where the widget is embedded:

```html
<!-- Email template -->
<a href="https://your-site.com/interactive-widget">
  <img src="https://your-site.com/images/widget-preview.png" 
       alt="Interactive Widget" />
</a>
```

### Landing Pages

Use widgets for interactive landing page elements:

- Calculators and configurators
- Interactive demos
- Data visualization
- Lead capture forms

## Analytics

### Google Analytics

Count how many visitors actually see the widget, by sending an event once it scrolls into view:

```typescript
const widgetElement = document.querySelector('widgetic[composition-id="YOUR_COMPOSITION_ID"]');

if (widgetElement) {
  const viewObserver = new IntersectionObserver((entries) => {
    if (entries.some((entry) => entry.isIntersecting)) {
      gtag('event', 'widget_viewed', {
        event_category: 'Widget',
        event_label: 'YOUR_COMPOSITION_ID'
      });
      viewObserver.disconnect(); // Count each page view once
    }
  }, { threshold: 0.5 });

  viewObserver.observe(widgetElement);
}
```

### Mixpanel

```typescript
const widgetElement = document.querySelector('widgetic[composition-id="YOUR_COMPOSITION_ID"]');

if (widgetElement) {
  const viewObserver = new IntersectionObserver((entries) => {
    if (entries.some((entry) => entry.isIntersecting)) {
      mixpanel.track('Widget Viewed', {
        composition_id: 'YOUR_COMPOSITION_ID'
      });
      viewObserver.disconnect();
    }
  }, { threshold: 0.5 });

  viewObserver.observe(widgetElement);
}
```

## Webhooks

<Warning>
  **Not available yet.** Widgetic does not send these events to your server today, and there is no Webhooks page in the dashboard. The design below is a sketch and may change.
</Warning>

### Events in the Sketch

| Event | Description |
|-------|-------------|
| `widget.created` | New widget created |
| `widget.updated` | Widget modified |
| `widget.published` | Widget published |
| `composition.saved` | Composition saved |

### Setup in the Sketch

1. Go to Dashboard → Settings → Webhooks
2. Add your endpoint URL
3. Select events to subscribe
4. Copy the signing secret

### Example Handler

```typescript
app.post('/webhooks/widgetic', (req, res) => {
  // Verify signature
  if (!verifySignature(req)) {
    return res.status(401).send('Invalid signature');
  }
  
  const { event, data } = req.body;
  
  switch (event) {
    case 'widget.published':
      // Update your cache
      cache.invalidate(`widget:${data.id}`);
      break;
    case 'composition.saved':
      // Sync to your database
      db.compositions.upsert(data);
      break;
  }
  
  res.status(200).send('OK');
});
```

## Other Languages

Widgetic does not publish a Python or PHP package. Any language that can send HTTPS requests can call the REST API, and every endpoint in the [API Reference](/api-reference/introduction) has request samples in several languages. For TypeScript, use the [API SDK](/resources/sdks).
